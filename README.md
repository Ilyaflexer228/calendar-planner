# 🎄 Новогодний движ 2027 — Совместный Планировщик Праздников

> Современное, стильное и функциональное веб-приложение для дружеских компаний, планирующих Новый год 2027 и праздничные каникулы.  
> Никаких корпоративных таск-менеджеров — только совместный отдых, выбор дат голосованием, списки участников и единый план!

🌐 **Онлайн-версия (GitHub Pages):**  
👉 **[https://ilyaflexer228.github.io/calendar-planner/](https://ilyaflexer228.github.io/calendar-planner/)**

## ✨ Ключевые возможности

### 1. 📅 Интерактивный Новогодний Календарь
* **Новогодний фокус:** Удобный быстрый переход к праздничному периоду (20 декабря 2026 — 10 января 2027).
* **Праздничные акценты:** Особое оформление для 31 декабря и 1 января с бейджами и отсчётом курантов.
* **Наглядные категории:** *🎄 Новый год*, *🎉 Вечеринка*, *🍕 Еда и кафе*, *🎮 Игры*, *🎬 Кино*, *🚗 Поездка*, *🏠 Домашние посиделки*, *✨ Другое*.
* **Детектор конфликтов расписания:** Предупреждает и подсвечивает пересечения по времени между подтверждёнными событиями.
* **Адаптивный мобильный режим:** На смартфонах календарь отображает компактные цветные маркеры, а под сеткой открывается подробная панель выбранного дня.

### 2. 🗳️ Предложения и Голосование за Даты
* Любой друг может предложить идею и указать **несколько альтернативных дат**.
* Участники голосуют в 1 клик:
  * ✅ *Подходит*
  * 🤔 *Возможно*
  * ❌ *Не подходит*
* Наглядные счетчики и аватары проголосовавших друзей.
* Организатор или автор идеи утверждает финальную дату, переводя событие в статус **«Подтверждено»**.

### 3. 🎯 Наш утверждённый план (Хронология)
* Чистый хронологический таймлайн со всеми согласованными событиями.
* **Подтверждение участия (RSVP):** *✅ Пойду*, *🤔 Не уверен*, *❌ Не смогу*.
* Список и аватары идущих друзей («Идут 5 человек»).
* Подсчёт общего примерного бюджета праздников.
* **Экспорт в календарь (.ics):** Добавление события или всей программы в Google Calendar, Apple Calendar или Outlook.

### 4. 💬 Обсуждение и детали
* К каждому мероприятию можно оставить комментарии для организационных вопросов («Кто принесёт салюты?», «Я поеду на машине, могу подвезти»).
* Указание точного места, времени, бюджета на человека и ссылки на локацию.

### 5. 👥 Простая авторизация и роли
* Вход по имени и праздничному аватару-смайлику без ввода паролей.
* Стабильный уникальный идентификатор сессии в браузере (UUID).
* Разделение ролей: Организатор (👑) и Участники.
* Название группы и подзаголовок редактируются организатором в настройках.

## 🎨 Дизайн и атмосфера
* **Тёмная тема по умолчанию:** глубокие оттенки индиго, графита и полуночного синего в стиле Linear / Notion Calendar.
* **Праздничные детали:** ненавязчивый падающий снег на Canvas (бережно относится к батарее, учитывает `prefers-reduced-motion`).
* **Живой таймер:** обратный отсчёт дней, часов, минут и секунд до Нового Года 2027.
* **Переключатель светлой темы** (`🌙` / `☀️`) с сохранением выбора.

## 🛠️ Архитектура и хранение данных

Приложение спроектировано без тяжёлых сборщиков и зависимостей, что обеспечивает 100% стабильную работу на GitHub Pages:

```
├── index.html               # Главная страница приложения
├── css/
│   └── styles.css           # Современная дизайн-система и адаптивные стили
├── js/
│   ├── config.js            # Конфигурация, категории, статусы, даты
│   ├── models.js            # Фабрики сущностей (Event, Vote, RSVP, Comment)
│   ├── storage.js           # Конфликт-устойчивый Storage Engine и миграции
│   ├── calendar.js          # Логика календаря, праздничных дат и конфликтов
│   ├── ui.js                # Табы, дашборд, модальные окна, экспорт .ics
│   ├── particles.js         # Легковесные праздничные снежинки на Canvas
│   └── app.js               # Главный координатор приложения
├── supabase/
│   └── migrations.sql       # Готовые SQL-миграции PostgreSQL + RLS + Realtime
└── README.md
```

### Двойной механизм синхронизации:
1. **Cloud KV (по умолчанию):** Работает «из коробки» без дополнительных регистраций. Поддерживает трёхстороннее слияние данных (Three-Way Merge), защищая от потери данных при одновременном редактировании несколькими друзьями.
2. **Supabase (опционально для Production):**
   * В папке `supabase/migrations.sql` подготовлен полный SQL-скрипт с созданием таблиц, внешних ключей, индексов, Row Level Security и публикацией Realtime.
   * Для подключения откройте настройки (`⚙️`) в шапке сайта и укажите ваши `Project URL` и `Anon Key`.

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Ilyaflexer228/calendar-planner.git
   cd calendar-planner
   ```

2. Запустите любой локальный статический сервер:
   ```bash
   python -m http.server 8000
   ```

3. Откройте в браузере: [http://localhost:8000](http://localhost:8000).
