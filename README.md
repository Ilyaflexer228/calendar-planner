# 🗓️ PlanSphere — Интерактивный Календарь Планирования

Современное веб-приложение календаря для удобного планирования событий, отслеживания сроков (дедлайнов) и управления задачами.

🌐 **Онлайн-версия (GitHub Pages):**  
[https://ilyaflexer228.github.io/calendar-planner/](https://ilyaflexer228.github.io/calendar-planner/)

---

## ✨ Основные возможности

- 📅 **Множество режимов просмотра:**
  - **Месяц:** классическая сетка с бейджами событий и индикатором текущего дня.
  - **Неделя:** подробная почасовая сетка (08:00–21:00) для точного распределения времени.
  - **День:** детальный таймлайн выбранного дня.
  - **Доска планов (Канбан):** визуализация статусов задач (*Запланировано*, *В процессе*, *Выполнено*) с drag-and-drop перемещением.
  - **Расписание (Agenda):** хронологический список всех событий с группировкой по датам.
- 🎯 **Фиксированные даты планирования и контроль дедлайнов:**
  - Установка целевой даты планирования (дедлайна).
  - Автоматический расчет оставшихся дней: *"Через 3 дн."*, *"Завтра"*, *"Дедлайн сегодня!"*, *"Просрочено на X дн."*.
- 🏷️ **Категории и приоритеты:**
  - Категории: *Работа*, *Личное*, *Учёба*, *Здоровье & Спорт*, *Цель / Веха*, *Встреча*.
  - Приоритеты: *Низкий*, *Средний*, *Высокий*, *🔥 Срочно*.
  - Фильтрация по категориям и приоритетам в один клик.
- 🔍 **Мгновенный поиск:** фильтрация по названию и описанию на лету.
- 💾 **Синхронизация и локальное сохранение:** все события мгновенно сохраняются в `localStorage` вашего браузера.
- 📤 **Экспорт и импорт:**
  - Экспорт календаря в стандартный формат **iCalendar (`.ics`)** для импорта в Google Calendar, Apple Calendar, Outlook.
  - Экспорт и импорт всей базы событий в **JSON**.
- 🌓 **Тёмная и светлая тема:** адаптивный дизайн с поддержкой тёмного режима и запоминанием выбора.
- 🎉 **Интерактивные анимации:** конфетти при успешном завершении целей и задач!

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Ilyaflexer228/calendar-planner.git
   cd calendar-planner
   ```
2. Откройте файл `index.html` в любом браузере (или запустите локальный сервер):
   ```bash
   python -m http.server 8000
   ```
3. Перейдите по адресу [http://localhost:8000](http://localhost:8000).
