# 🗓️ Простой Календарь Событий с Общим Доступом

Легкий, быстрый и удобный календарь событий. Ничего лишнего — просто выберите дату, укажите время и название. Все изменения автоматически сохраняются и видны любому пользователю!

🌐 **Онлайн-сайт (GitHub Pages):**  
[https://ilyaflexer228.github.io/calendar-planner/](https://ilyaflexer228.github.io/calendar-planner/)

---

## ⚡ Особенности

- 👆 **Добавление в один клик:** просто нажмите на любой день месяца.
- 🕒 **Только нужные поля:** Дата, Время и Название события.
- ✏️ **Легкое редактирование и удаление:** нажмите на любое существующее событие, чтобы изменить его или удалить.
- 🌍 **Общий доступ и синхронизация:** события сохраняются в облаке и сразу доступны всем пользователям по ссылке.
- 💾 **Автономная работа:** также сохраняется в локальной памяти браузера (LocalStorage).
- 📱 **Адаптивный интерфейс:** отлично работает на смартфонах, планшетах и компьютерах.
